# Deadlock News Discord Bot

Discord-бот, который автоматически постит свежие новости об игре **Deadlock** (Valve) в выбранный канал на вашем сервере: патч-ноуты, обновления, анонсы.

## Источники новостей

- **Steam News API** — официальные анонсы Valve для appid `1422450` (Deadlock).
- **forums.playdeadlock.com Changelog RSS** — патч-ноуты с официального форума.

Бот опрашивает оба источника каждые 5 минут (настраивается) и публикует только новые посты, которых ещё не было.

---

## Что нужно для запуска

- **Python 3.10+** (проверьте `python --version`)
- **Discord-аккаунт** и сервер, куда добавить бота (нужны права администратора на сервере)
- 5 минут времени

---

## Шаг 1 — Создать приложение и бота в Discord

1. Открыть https://discord.com/developers/applications и нажать **New Application**.
2. Ввести имя (например, `Deadlock News`), нажать **Create**.
3. Слева перейти во вкладку **Bot** → **Reset Token** → скопировать токен. **Никому его не показывайте**, токен = пароль от бота.
4. На той же вкладке **Bot** в разделе **Privileged Gateway Intents** включать ничего не нужно — боту хватает обычных прав.

## Шаг 2 — Пригласить бота на свой сервер

1. Слева перейти во вкладку **OAuth2** → **URL Generator**.
2. В **Scopes** отметить `bot` и `applications.commands`.
3. В **Bot Permissions** отметить:
   - View Channels
   - Send Messages
   - Embed Links
   - Read Message History
4. Скопировать сгенерированную ссылку внизу, открыть её в браузере, выбрать сервер и нажать **Authorize**.

## Шаг 3 — Скачать и установить бота

```bash
git clone <URL вашего репозитория>
cd deadlock-discord-bot

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

## Шаг 4 — Настроить токен

В папке проекта скопируйте `.env.example` в `.env`:

```bash
# Windows
copy .env.example .env

# macOS / Linux
cp .env.example .env
```

Откройте файл `.env` в любом текстовом редакторе и впишите туда токен бота:

```
DISCORD_TOKEN=ваш_токен_сюда
POLL_INTERVAL_MINUTES=5
```

## Шаг 5 — Запустить

```bash
python bot.py
```

В консоли должно появиться `Logged in as Deadlock News#1234`. Бот работает, пока окно консоли открыто. Закрыли консоль — бот выключился.

## Шаг 6 — Указать канал для новостей

На вашем сервере в Discord введите слэш-команду:

```
/setchannel #название-канала
```

Команду видят только администраторы. После этого новые патч-ноуты и анонсы будут автоматически приходить в указанный канал.

> При самом первом запуске бот **не** постит всю историю — он просто запоминает, что уже есть, и начнёт публиковать только то, что появится дальше. Это сделано специально, чтобы канал не завалило старыми патчами.

---

## Команды

| Команда                 | Что делает                                                         |
|-------------------------|--------------------------------------------------------------------|
| `/setchannel #channel`  | Выбрать канал для новостей (только админ).                         |
| `/news`                 | Опубликовать 3 последние новости прямо сейчас.                     |
| `/status`               | Показать текущий канал, интервал опроса, время последней проверки. |

## Локальная проверка источников новостей

Если хотите убедиться, что сами источники отвечают (без подключения к Discord):

```bash
python test_news.py
```

Скрипт распечатает в консоли последние новости из Steam и форума.

## Частые проблемы

**Бот не отвечает на слэш-команды.** Подождите 1–2 минуты после запуска — Discord иногда подгружает команды с задержкой. Если не помогло — кикните бота с сервера и снова пригласите по ссылке из шага 2 (важно, чтобы был scope `applications.commands`).

**`DISCORD_TOKEN is missing`.** Файл `.env` создан не в той папке или внутри неправильное имя переменной. Должно быть строго `DISCORD_TOKEN=...`.

**`pip install` ругается на discord.py.** Проверьте версию Python — нужен 3.10 или выше.

**Хочу сменить интервал опроса.** В `.env` поменяйте `POLL_INTERVAL_MINUTES`. Минимум — 1 минута, разумный диапазон — 5–15 минут.

**Бот должен работать 24/7.** Сейчас он работает только пока запущена консоль на вашем ПК. Чтобы крутился постоянно — нужен сервер (VPS, Railway, fly.io). Это следующий шаг, спросите когда будете готовы.
